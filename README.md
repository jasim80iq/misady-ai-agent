# مساعدي الذكي 🤖

وكيل عراقي متعدد المهام كبداية: فيديو، صور وإعلانات، سوشيال ميديا، ردود الزبائن وملفات.

## تشغيل محلي
```bash
pip install -r requirements.txt
streamlit run app.py
```

## المرحلة التالية
- ربط نموذج ذكاء اصطناعي فعلي.
- ذاكرة للمشروع.
- قراءة وتلخيص الملفات.
- أدوات صناعة الصور والفيديو.
- تنفيذ مهام خارجية مع تأكيد قبل الإجراءات الحساسة.
